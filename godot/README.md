The default scene now runs the Rust-backed fleet simulator. See [the main README](../README.md) for title/menu, Solo/Massive modes, orders, apartment delivery, cameras, persistence, and Make commands. The flight campaign below remains a legacy scenario, available with `-- --ai-demo`.

# COAST — AI Drone Simulator

Open `project.godot` in Godot 4.7 and press F5, or run:

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path godot
```

The active world uses real OpenStreetMap geometry and public terrain elevation at **1 unit = 1 metre**, with east +X and north -Z. See [MAP_REFERENCES.md](MAP_REFERENCES.md) for source accuracy, height estimates, and remaining limitations. Data licensing is in [data/LICENSE.md](data/LICENSE.md).

Choose a sandwich, coffee, or a sandwich + coffee set and a quantity of 1–3, then click **PLACE ORDER / AI DELIVERY** (or Enter). The drone delivers to the Peace Gate picnic point, marks the order delivered, and returns to base. **NEW ORDER** opens the menu again. Orders are fictional and require no payment; one order is handled at a time.

Choose **TRAINING CAMPAIGN** for the original autonomous three-task sortie. Complete lunch delivery, deploy rescue flotation over Mongchon Lake, inspect the KSPO Dome roof, and return to base. Tasks award 300, 500 and 400 points; a successful return adds a battery and hull bonus. Battery drains with flight, impacts damage the hull, and depleted power or hull ends the run. Below 20% battery the AI returns automatically; docking recharges and repairs before resuming.

Click to capture the mouse. WASD moves relative to camera heading, mouse orbits the camera, Space/Ctrl climbs/descends, Shift boosts (65 m/s versus 22 m/s normal), wheel zooms, Escape releases the cursor and R restarts the game. **Tab** toggles autonomous flight, movement keys immediately take manual control, and **H** commands return to base. During manual flight, hold **F** within 2.5 metres of the target while moving slower than 1.25 m/s for the service timer to complete. The AI performs the same timed service automatically.

The autonomous pilot is an offline, rule-based controller: it samples terrain and roofs, plans climb/cruise/approach waypoints, brakes near targets, and uses physics shape casts to detect obstacles. It is not a learned model or a real aircraft navigation system. Flight bounds follow the map extract, with a ceiling 650 m above the local elevation datum. The HUD shows terrain-relative altitude, heading, coordinates, battery, hull, score and mission progress.

All dispatches are fictional game events. The 32 Minecraft-style pedestrians walk along mapped paths. Only mapped tree points are instantiated; this is not a complete tree inventory.

Add `-- --buildings-view` to start above the stadium district. The editable aircraft is `../blender/coast_drone.blend`; its exported asset is `assets/coast_drone.glb`.

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path godot --editor --import
/Applications/Godot.app/Contents/MacOS/Godot --headless --path godot -- --smoke
/Applications/Godot.app/Contents/MacOS/Godot --headless --path godot --fixed-fps 60 -- --ai-test
/Applications/Godot.app/Contents/MacOS/Godot --headless --path godot --fixed-fps 60 -- --order-test
/Applications/Godot.app/Contents/MacOS/Godot --path godot -- --capture --ai-demo
/Applications/Godot.app/Contents/MacOS/Godot --path godot -- --capture --buildings-view
```

The old compressed layout scripts remain as unused prototypes. All active map content is generated by `scripts/real_map.gd` from `data/real-map.json`.

The AI test flies the complete three-task campaign and lands, then checks manual takeover/resume, low-battery return, collision failure, restart, manual service, scoring and roof clearance. The simulation uses simplified flight physics; wind, aerodynamics, payload dynamics and real operational restrictions are not modeled.

## Water rendering

All nine mapped water surfaces use `assets/lake_water.gdshader`, a native Godot spatial ShaderMaterial: animated world-space ripple normals, depth-buffer-based alpha transparency and absorption, Fresnel highlights, shoreline intersection foam, and ReflectionProbe scene reflections. The shader preserves footprint vertices and water elevations. It supports the project's Metal/Mobile renderer and includes Compatibility depth reconstruction. These are visual effects, not fluid physics or surveyed bathymetry.

Run with `-- --water-view` to start over 88 Lake. Shader uniforms expose ripple strength, animation speed, roughness, absorption and shallow/deep tint. Reflection probes update once for static surroundings and exclude water to avoid self-reflections. The water casts no opaque shadow. `--capture --water-view` produces two PNGs one second apart for animation comparison.

Validation: the map/flight smoke suite passes and a water-only image region visibly changes between frames. Godot 4.7.2 Metal currently reports seven texture RIDs at graphical process shutdown with this effect; capture succeeds and no runtime script/shader error occurs. The warning remains a renderer cleanup limitation.

Godot reference: https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/spatial_shader.html
